# 我的世界手环表盘安装器 Lua 源码

本仓库公开小米 Vela 手环上使用的《我的世界》表盘安装器 Lua 源码，供代码审阅、修改和再分发。

## 内容

- `lua/q66/installer.lua`：小米手环 11（q66）安装器入口。
- `lua/o66/installer.lua`：小米手环 10（o66）安装器入口。
- `lua/shared/`：共享的界面、进度和应用显隐管理模块。
- `PROTOCOL.md`：公开的设备接口和宿主约定。

Lua 文件保持项目发布版本的内容，没有为了公开仓库改写实现。仓库不包含 Minecraft 原生 ELF、主题资源、固件地址、私有恢复实现、签名材料或内部构建配置。
